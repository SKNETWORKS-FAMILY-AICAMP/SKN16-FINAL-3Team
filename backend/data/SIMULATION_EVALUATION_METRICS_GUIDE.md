# 🎯 시뮬레이션 평가 지표 가이드

## 📌 개요

이 문서는 **은행 신입행원 고객 응대 시뮬레이션 평가 시스템**의 평가 지표를 설명하는 가이드입니다.  
시뮬레이션을 완료하면 5가지 역량이 평가되며, 각 역량은 0-100점 척도로 평가됩니다.

---

## 🏆 평가 역량 (5가지)

시뮬레이션 평가는 다음 **5가지 역량**을 평가합니다:

| 역량 | 가중치 | 설명 |
|------|--------|------|
| **1. 지식** (Knowledge) | 20% | 은행 상품 및 금융 지식의 정확성 |
| **2. 기술** (Skill) | 20% | 응대 절차의 체계성 및 목표 달성도 |
| **3. 친절도** (Kindness) | 20% | 고객 중심의 배려 있는 언어 사용 |
| **4. 전달력** (Communication) | 20% | 명확하고 자신감 있는 정보 전달 |
| **5. 페르소나 정합도** (Persona Fit) | 20% | 고객 유형에 맞는 적절한 대응 전략 |

### 종합 점수 계산

```
종합 점수 = (지식 × 20%) + (기술 × 20%) + (친절도 × 20%) + (전달력 × 20%) + (페르소나 정합도 × 20%)
```

### 등급 산정

| 종합 점수 | 등급 | 평가 |
|----------|------|------|
| 90점 이상 | **A** | 탁월한 성과 |
| 80-89점 | **B** | 우수한 성과 |
| 70-79점 | **C** | 양호한 성과 |
| 60-69점 | **D** | 보통 수준 |
| 60점 미만 | **F** | 개선 필요 |

---

## 📊 각 역량별 상세 평가 기준

### 1️⃣ 지식 (Knowledge) - 100점 만점, 가중치 20%

#### 평가 목적
은행 상품(예금, 대출, 카드 등)에 대한 설명이 **정확한지**를 평가합니다.

#### 평가 기준

**✅ 높은 점수를 받으려면:**
- 상품 정보(금리, 한도, 조건, 절차 등)를 **정확하게** 제공
- 일반적인 금융 지식 및 규정을 올바르게 이해하고 설명
- 잘못된 정보나 추측성 정보 제공하지 않기

**❌ 감점 요인:**
- 잘못된 정보 제공 시 (예: 실제 금리와 다른 금리 제시)
- 부정확한 절차나 조건 안내
- 규정 위반 내용 포함

#### 평가 예시

**좋은 예:**
```
고객: "정기예금 금리가 궁금한데요"
직원: "하경 정기예금의 기본 금리는 연 2.15%입니다. 
       1천만원 이상 예치 시 우대금리 0.5%p 추가로 연 2.65%까지 가능합니다."
```
→ ✅ 정확한 금리 정보 제공 (100점)

**나쁜 예:**
```
고객: "정기예금 금리가 궁금한데요"
직원: "기본 금리는 연 3.5%입니다."
```
→ ❌ 실제 금리(2.15%)와 다름 → 감점

#### 점수 향상 팁

1. **상품 정보 사전 확인**: 시뮬레이션 전 관련 상품 정보를 숙지
2. **수치 확인**: 금리, 한도 등 구체적 수치는 정확히 확인 후 제시
3. **모르는 정보 추측 금지**: 확실하지 않은 정보는 확인 후 안내

---

### 2️⃣ 기술 (Skill) - 100점 만점, 가중치 20%

#### 평가 목적
응대 절차가 **체계적이며 목표를 달성**했는지를 평가합니다.

#### 점수 구성

| 항목 | 배점 | 평가 내용 |
|------|------|-----------|
| **대화 흐름** | 20점 | 인사 → 요구파악 → 정보제공 → 마무리 순서 |
| **목표 달성도** | 60점 | 시뮬레이션 목표(goal_list) 달성률 |
| **질문 사용** | 10점 | 고객 니즈 파악을 위한 적절한 질문 사용 |
| **피드백 루프** | 10점 | 요약 및 추가 확인 여부 |

#### 평가 기준

**✅ 대화 흐름 (20점)**
- 인사 및 초기 관계 형성 (5점)
- 고객 요구사항 파악 (7점)
- 정보 제공 및 설명 (5점)
- 적절한 마무리 (3점)

**✅ 목표 달성도 (60점)**
- 각 목표별 달성 여부 평가
- 목표 텍스트에 명시된 구체적 키워드가 실제로 다뤄졌는지 확인
- 예: 목표가 "고객의 문의 의도와 현재 금융 상황(소득, 거래 패턴 등)을 정확히 파악한다"인 경우
  - ✅ 소득과 거래 패턴을 물어봤으면 목표 달성
  - ❌ 소득과 거래 패턴을 물어보지 않았으면 목표 미달성

**✅ 질문 사용 (10점)**
- 개방형 질문 활용 여부
- 고객 상황 파악을 위한 질문의 적절성
- 예: "어떤 용도로 사용하실 계획이신가요?" (개방형 질문 ✅)

**✅ 피드백 루프 (10점)**
- 고객 말을 정리하여 확인
- 추가 질문 유도
- 고객의 이해도 확인

#### 평가 예시

**좋은 예:**
```
1. 인사: "안녕하세요, 무엇을 도와드릴까요?"
2. 요구파악: "어떤 용도로 사용하실 계획이신가요? 예치 기간은 어떻게 되시나요?"
3. 정보제공: "하경 자유입출금통장은 이렇게 되어 있습니다..."
4. 확인: "제가 설명드린 내용 이해되시나요? 추가로 궁금한 점 있으신가요?"
5. 마무리: "그럼 수고하세요. 좋은 하루 되세요."
```
→ ✅ 체계적인 대화 흐름, 목표 달성, 질문 사용, 확인 단계 포함 (95점)

**나쁜 예:**
```
직원: "안녕하세요. 정기예금 하실래요?"
고객: "네"
직원: "금리 2.15%입니다. 끝."
```
→ ❌ 요구파악 없음, 확인 없음, 목표 미달성 (40점)

#### 점수 향상 팁

1. **대화 단계 순서 기억**: 인사 → 파악 → 제공 → 확인 → 마무리
2. **목표 확인**: 시뮬레이션 시작 전 목표 리스트를 확인하고 각 목표를 달성하도록 노력
3. **질문 활용**: 고객의 상황을 파악하기 위해 다양한 질문 사용
4. **확인 단계**: 설명 후 고객이 이해했는지 확인

---

### 3️⃣ 친절도 (Kindness) - 100점 만점, 가중치 20%

#### 평가 목적
고객 중심의 **배려 있는 언어**를 사용했는지를 평가합니다.

#### 점수 구성

| 항목 | 배점 | 평가 내용 |
|------|------|-----------|
| **기본 정중함 및 긍정 표현** | 30점 | 전반적으로 정중한 어투 유지 |
| **고객 선택권 존중 및 배려** | 25점 | 선택권 존중 표현 사용 |
| **공감 및 이해 표현** | 20점 | 고객 불편/불만에 대한 공감 표현 |
| **추가 도움 제공 의지** | 10점 | 추가 도움 제공 의지 명확히 표현 |
| **부정 표현 회피** | 15점 | 부정 표현 사용 시 감점 |

#### 평가 기준

**✅ 긍정 표현 예시:**
- "감사합니다"
- "도와드리겠습니다"
- "안내해 드리겠습니다"
- "~해주세요", "~드리겠습니다"
- "추가로 궁금한 점 있으시면 언제든지 문의해 주세요"

**❌ 부정 표현 예시 (감점):**
- "안 됩니다"
- "불가능합니다"
- "모르겠어요"
- 명령형/무뚝뚝한 표현
- 강제적인 표현 (예: "더 빠르고 정확합니다" → "더 편리할 수 있습니다"로 변경 권장)

#### 고객 유형별 특별 평가

**불만형 고객:**
- 불만 표현에 적절히 공감하고 사과
- 해결책 제시
- 예: "불편을 드려 죄송합니다. 빠르게 해결해 드리겠습니다"

**급함형 고객:**
- 빠른 응답과 효율적인 안내
- 시간 존중 표현
- 예: "바로 처리해 드리겠습니다", "간단히 설명드리겠습니다"

**긍정형 고객:**
- 기본적인 친절도 평가 (위 일반 기준 적용)

#### 평가 예시

**좋은 예:**
```
고객: "처리가 너무 오래 걸리네요"
직원: "불편을 드려 정말 죄송합니다. 이해하시기 어려우셨을 것 같습니다. 
       바로 처리해 드리겠습니다. 10분 이내로 완료될 예정입니다."
```
→ ✅ 공감 표현, 사과, 구체적 해결책 제시 (95점)

**나쁜 예:**
```
고객: "처리가 너무 오래 걸리네요"
직원: "그건 저한테 문제가 없는데요. 규정상 그렇게 되어 있습니다."
```
→ ❌ 공감 없음, 방어적 태도, 부정적 표현 (20점)

#### 점수 향상 팁

1. **긍정 표현 습관화**: "~드리겠습니다", "~해주세요" 같은 배려 표현 자주 사용
2. **부정 표현 회피**: "안 됩니다" 대신 "~하는 방법이 있습니다"로 재구성
3. **고객 상황 파악**: 고객이 불만스러워하면 공감, 급해하면 빠른 처리 강조

### 4️⃣ 전달력 (Communication) - 100점 만점, 가중치 20%

#### 평가 목적
**명확하고 자신감 있는** 정보 전달 능력을 평가합니다.  
전달력은 **명확성**과 **자신감**을 종합하여 평가됩니다.

#### 명확성 (Clarity) 평가

**점수 구성:**

| 항목 | 배점 | 평가 기준 |
|------|------|-----------|
| **문장 구조 및 간결성** | 30점 | 평균 문장 길이 (50자 이하 권장) |
| **논리성 및 구조** | 25점 | 논리적 순서, 연결어 적절 사용 |
| **용어 평이성** | 30점 | 전문용어 → 쉬운 말 변환 |
| **숫자 표현의 명확성** | 15점 | 단위 명시 등 |

**✅ 좋은 예:**
- "거치기간" → **"이자만 내는 기간"**
- "언택트" → **"비대면"**
- "LTV" → **"담보인정비율"**
- "복리" → **"이자에 이자가 붙는 방식"**
- "최소 100" → **"최소 100만원"** (단위 명시)

#### 자신감 (Confidence) 평가

**점수 구성:**

| 항목 | 배점 | 평가 기준 |
|------|------|-----------|
| **확정적 표현 비율** | 80점 | 전체 발언 중 확정적 표현 비율 (90% 이상 권장) |
| **모호 표현 회피** | 20점 | 모호 표현 사용 시 감점 |

**✅ 확정적 표현 예시:**
- "~합니다"
- "~됩니다"
- "~가능합니다"
- "맞습니다"

**❌ 모호 표현 예시 (감점):**
- "~같아요"
- "~일 수도 있어요"
- "~보이는데요"
- "확실하진 않지만"
- "아마도"
- "모르겠지만"

#### 평가 예시

**좋은 예:**
```
직원: "하경 자유입출금통장의 기본 금리는 연 2.15%입니다. 
      1천만원 이상 예치 시 우대금리 0.5%p 추가로 연 2.65%까지 가능합니다."
```
→ ✅ 명확한 문장 구조, 단위 명시, 확정적 표현 (95점)

**나쁜 예:**
```
직원: "음... 금리가 아마도 2% 정도 같아요. 그리고 최소는 100 정도인 것 같고..."
```
→ ❌ 모호 표현 과다, 단위 미명시, 불확실한 어투 (30점)

#### 전달력 점수 계산

```
전달력 점수 = (명확성 점수 + 자신감 점수) / 2
```

#### 점수 향상 팁

1. **간결한 문장**: 한 문장을 50자 이내로 작성 (평균)
2. **전문용어 변환**: 어려운 용어는 쉬운 말로 설명
3. **단위 명시**: 숫자 뒤에는 항상 단위(만원, %, 등) 명시
4. **확정적 어투**: "~같아요" 대신 "~입니다" 사용
5. **논리적 순서**: 중요한 정보부터 순서대로 전달

### 5️⃣ 페르소나 정합도 (Persona Fit) - 100점 만점, 가중치 20%

#### 평가 목적
고객 **페르소나 타입에 맞는 대응 전략**을 체계적으로 사용했는지 평가합니다.

#### 고객 유형별 평가 기준

### A. 불만형 고객 (타입: "불만형")

**점수 구성:**

| 항목 | 배점 | 평가 내용 |
|------|------|-----------|
| **공감 및 사과 표현** | 50점 | 고객 불만 표현 직후 공감/사과 (문맥 중심 평가) |
| **해결책 제시** | 40점 | 공감 후 구체적 해결책 제시 |
| **부정 패턴 회피** | 10점 | 부정 표현 사용 시 감점 |

**✅ 평가 기준:**
- 고객이 불만을 표현한 **직후 1-2턴 이내** 공감/사과
- 구체적이고 진정성 있는 공감 표현
- 자연스러운 대화 흐름: 불만 → 공감 → 해결책
- 구체적이고 실현 가능한 해결책 제시

**✅ 좋은 예:**
```
고객: "왜 이렇게 복잡하죠? 이해가 안 되는데요"
직원: "불편을 드려 정말 죄송합니다. 이해하시기 어려우셨을 것 같습니다. 
      간단히 설명드리겠습니다. 먼저 기본 구조를..."
```
→ ✅ 불만 표현 직후 즉시 공감/사과, 구체적 해결책 제시 (95점)

### B. 급함형 고객 (타입: "급함형")

**점수 구성:**

| 항목 | 배점 | 평가 내용 |
|------|------|-----------|
| **빠른 처리 표현 및 대응** | 40점 | 고객 급함 표현 직후 빠른 처리 의지 표명 |
| **문장 간결성 및 효율성** | 40점 | 급함 상황에 맞는 간결한 설명 (평균 40자 이하 권장) |
| **핵심 정보 전달 및 순서** | 20점 | 질문에 직접 답변, 핵심 정보 우선 전달 |

**✅ 평가 기준:**
- 고객 급함 표현 직후 **즉시 빠른 처리 의지** 표시
- 핵심 정보만 간결하게 전달 (불필요한 부가 설명 회피)
- 질문에 바로 답변, 핵심 정보를 먼저 전달

**✅ 좋은 예:**
```
고객: "빨리 해야 하는데요"
직원: "바로 처리해 드리겠습니다. 금리는 연 2.15%, 최소 예치금은 10만원입니다."
```
→ ✅ 즉시 빠른 처리 의지 표시, 간결한 핵심 정보 전달 (95점)

**❌ 나쁜 예:**
```
고객: "빨리 해야 하는데요"
직원: "네, 그런데 먼저 이 상품의 배경을 설명드리면..."
```
→ ❌ 급함 상황 무시, 불필요한 설명부터 시작 (30점)

### C. 긍정형 고객 (타입: "긍정형")

**점수 구성:**

| 항목 | 배점 | 평가 내용 |
|------|------|-----------|
| **긍정 표현 및 대응** | 60점 | 고객 긍정 반응에 적절히 긍정적으로 대응 |
| **추가 안내 제공** | 40점 | 적절한 시점에 유용한 추가 안내 제공 |

**✅ 평가 기준:**
- 고객의 긍정적 표현에 자연스럽게 긍정적으로 대응
- 전반적으로 긍정적이고 친절한 분위기 유지
- 고객이 추가 정보를 필요로 할 때 적절히 제공
- 친절한 마무리 및 지속적 관심 표현

**✅ 좋은 예:**
```
고객: "좋네요! 이 상품 좋아 보이는데요"
직원: "감사합니다. 고객님께서 만족하시니 저도 기쁩니다. 
      추가로 이런 서비스도 있어요. 더 궁금한 점 있으시면 언제든 말씀해 주세요."
```
→ ✅ 긍정 반응, 추가 안내, 친절한 마무리 (95점)

#### 평가 시 주의사항

⚠️ **문맥 중심 평가:**
- 단순히 키워드나 표현의 개수를 세는 것이 아님
- **언제, 어떤 상황에서, 어떻게** 사용했는지 평가
- 고객의 발화를 먼저 읽고, 그에 대한 직원의 응대가 적절한 시점인지, 자연스러운지 평가

**예시:**
- 공감 표현이 3회 있어도 부적절한 시점에 사용했다면 → 낮은 점수
- 공감 표현이 1회만 있어도 고객 불만 표현 직후 적절한 시점에 구체적으로 사용했다면 → 높은 점수

#### 점수 향상 팁

1. **고객 유형 파악**: 시뮬레이션 시작 전 고객 유형 확인
2. **적절한 시점 대응**: 고객의 상황 변화(불만/급함/긍정 표현) 직후 1-2턴 내 대응
3. **유형별 전략 적용**:
   - 불만형: 공감 → 사과 → 해결책
   - 급함형: 빠른 처리 의지 → 간결한 핵심 정보
   - 긍정형: 긍정적 대응 → 추가 안내

## 💡 종합 점수 향상 전략

### 단계별 접근

1. **기초 단계 (60-70점)**
   - 정확한 정보 제공 (지식)
   - 기본적인 대화 흐름 따르기 (기술)

2. **중급 단계 (70-80점)**
   - 친절한 표현 습관화 (친절도)
   - 명확하고 간결한 설명 (전달력)

3. **고급 단계 (80-90점)**
   - 고객 유형에 맞는 대응 (페르소나 정합도)
   - 목표 완전 달성 (기술)

4. **탁월 단계 (90점 이상)**
   - 모든 역량 균형 있게 우수한 수준
   - 고객 만족도 극대화

### 역량별 우선순위

**초보자 우선순위:**
1. 지식 (정확한 정보 제공)
2. 기술 (기본 대화 흐름)
3. 친절도 (기본 정중함)

**중급자 우선순위:**
4. 전달력 (명확하고 자신감 있는 설명)
5. 페르소나 정합도 (고객 유형별 대응)

## 📈 평가 결과 해석

### 리포트 읽는 방법

평가 리포트는 다음 정보를 포함합니다:

1. **종합 점수 및 등급**: 전체적인 성과 수준
2. **역량별 점수**: 5가지 역량 각각의 점수
3. **상세 피드백**: 각 역량별 잘한 점과 개선점
4. **종합 요약**: 전반적인 강점과 핵심 개선점
5. **실천 방안**: 다음 시뮬레이션에서 즉시 적용 가능한 구체적 조언

### 약점 파악 방법

1. **가장 낮은 역량 점수** 확인
2. **평균 점수보다 낮은 역량** 확인
3. **개선점 섹션**에 명시된 항목 확인
4. 해당 역량의 평가 기준 다시 읽고 개선 방안 수립

### 점수 분포 이해

**평균적인 수준:**
- 대부분의 신입행원은 초기 60-75점 범위
- 80점 이상: 양호한 수준
- 85점 이상: 우수한 수준
- 90점 이상: 탁월한 수준

**역량별 평균 점수 (참고):**
- 지식: 70-75점
- 기술: 65-70점
- 친절도: 80-85점
- 전달력: 70-75점
- 페르소나 정합도: 65-70점

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 모든 역량을 100점 받아야 하나요?
A. 아니요. 종합 점수 90점 이상(A등급)만 받으면 됩니다. 모든 역량이 균형 있게 우수한 수준이면 됩니다.

### Q2. 한 역량이 매우 낮아도 다른 역량이 높으면 보완되나요?
A. 어느 정도 보완은 되지만, 가중치가 동일하므로(각 20%) 모든 역량을 균형 있게 향상시키는 것이 중요합니다.

### Q3. 목표 달성도가 낮으면 기술 점수가 크게 떨어지나요?
A. 네. 목표 달성도는 기술 점수의 60%를 차지하므로 매우 중요합니다. 시뮬레이션 시작 전 목표를 확인하고 각 목표를 달성하도록 노력하세요.

### Q4. 고객 유형을 어떻게 알 수 있나요?
A. 시뮬레이션 시작 전 고객 정보에 유형이 표시됩니다. 불만형, 급함형, 긍정형 중 하나입니다.

### Q5. 모르는 정보를 물어봤을 때 어떻게 해야 하나요?
A. 추측하지 말고 "확인 후 안내해 드리겠습니다" 또는 "관련 담당자에게 문의 후 알려드리겠습니다"라고 말하는 것이 좋습니다.
