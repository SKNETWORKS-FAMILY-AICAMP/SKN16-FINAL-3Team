# 멘토-멘티 매칭 문제 해결 가이드

## 문제 상황
- 관리자 대시보드에서는 매칭이 완료되어 보이지만
- 개인 계정(멘토/멘티)으로 로그인하면 매칭이 안 되어 있는 것으로 표시됨

## 추가된 기능

### 1. 멘토가 멘티의 학습 현황 조회 API

#### 학습 현황 종합 조회
```
GET /dashboard/mentor/mentee/{mentee_id}/learning-progress
```
- 멘토가 담당 멘티의 전체 학습 현황을 조회할 수 있습니다
- 시뮬레이션, 퀴즈, 시험 점수 등 모든 학습 데이터 포함

#### 퀴즈 기록 조회
```
GET /dashboard/mentor/mentee/{mentee_id}/quiz-history
```
- 멘티의 퀴즈 기록 목록 조회

#### 시뮬레이션 기록 조회
```
GET /dashboard/mentor/mentee/{mentee_id}/simulation-history
```
- 멘티의 시뮬레이션 기록 목록 조회

### 2. 매칭 진단 API

#### 멘토 이름으로 매칭 진단
```
GET /dashboard/admin/diagnose-matching/{mentor_name}
```
- 특정 멘토의 매칭 상태 확인
- 활성/비활성 매칭 관계 모두 조회
- 예: `/dashboard/admin/diagnose-matching/권도형`

#### 멘티 이름으로 매칭 진단
```
GET /dashboard/admin/diagnose-mentee-matching/{mentee_name}
```
- 특정 멘티의 매칭 상태 확인
- 예: `/dashboard/admin/diagnose-mentee-matching/홍예미`

## 문제 진단 방법

### 1. 관리자 계정으로 로그인하여 진단 API 호출

#### 멘토 매칭 상태 확인
```bash
curl -X GET "http://localhost:8000/dashboard/admin/diagnose-matching/권도형" \
  -H "Authorization: Bearer {admin_token}"
```

#### 멘티 매칭 상태 확인
```bash
curl -X GET "http://localhost:8000/dashboard/admin/diagnose-mentee-matching/홍예미" \
  -H "Authorization: Bearer {admin_token}"
```

## 해결 방법

### 방법 1: 관리자 대시보드에서 재매칭
1. 관리자 대시보드 접속
2. 매칭 관리 페이지 이동
3. 해당 멘토-멘티 관계 재생성

### 방법 2: API를 통한 직접 수정 (DB 직접 접근 필요)
```sql
-- 활성 관계가 없는 경우, 기존 관계를 활성화
UPDATE mentor_mentee_relations 
SET is_active = TRUE 
WHERE mentor_id = {mentor_id} 
  AND mentee_id = {mentee_id};
```

### 방법 3: 관리자 API를 통한 매칭 재생성
```
POST /dashboard/admin/assign-mentor
{
  "mentee_id": 1016,
  "mentor_id": 1001,
  "notes": "매칭 재생성"
}
```

## 예상 원인

1. **Seed 데이터 로딩 시 문제**
   - Seed 데이터에는 매칭 정보가 있지만, 실제 DB에 반영되지 않았을 수 있음
   - `is_active` 필드가 `False`로 설정되었을 수 있음

2. **사용자 ID 매핑 문제**
   - Seed 데이터의 사용자 ID와 실제 DB의 사용자 ID가 다를 수 있음
   - 매칭 관계 생성 시 잘못된 ID가 사용되었을 수 있음

3. **매칭 관계 비활성화**
   - 어딘가에서 매칭 관계가 비활성화(`is_active=False`)되었을 수 있음

## 확인 사항

### 1. DB에서 직접 확인
```sql
-- 특정 멘토의 매칭 관계 확인
SELECT r.*, m1.name as mentor_name, m2.name as mentee_name
FROM mentor_mentee_relations r
JOIN users m1 ON r.mentor_id = m1.id
JOIN users m2 ON r.mentee_id = m2.id
WHERE m1.name = '권도형';

-- 활성 관계만 확인
SELECT r.*, m1.name as mentor_name, m2.name as mentee_name
FROM mentor_mentee_relations r
JOIN users m1 ON r.mentor_id = m1.id
JOIN users m2 ON r.mentee_id = m2.id
WHERE m1.name = '권도형' AND r.is_active = TRUE;
```

### 2. 멘토 대시보드 API 확인
```
GET /dashboard/mentor
```
- 로그인한 멘토의 담당 멘티 목록이 반환되는지 확인

### 3. 멘티 대시보드 API 확인
```
GET /dashboard/mentee
```
- 로그인한 멘티의 담당 멘토 정보가 반환되는지 확인
