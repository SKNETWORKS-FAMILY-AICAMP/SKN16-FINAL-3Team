# 시험 점수 수정 계획

## 발견된 문제점

### 1. Seed 데이터 문제
- **하경은행 점수**: cohort_3_2025.json에서 90개 중 86개가 10점 (95.6%)
- **영역별 분포**: 균등하지 않음, 특정 영역에 편향됨
- **초기/중간/최종 성장**: 점진적 성장 패턴이 없음

### 2. 시험 점수 생성 로직
- `_generate_section_scores_for_total`: 균등 분배 로직이 있지만, seed 데이터는 하드코딩
- 점진적 성장을 보장하는 로직 없음

### 3. 문제 정오답 정보
- **ExamResult**: 실제 시험 제출 시 저장됨 (exam_service.py)
- **QuizGenerationLog**: 퀴즈 결과는 저장되지만, seed 데이터에는 정오답 정보 없음

## 해결 방안

### 1. Seed 데이터 수정
- 하경은행 점수를 5~10점 범위로 다양화
- 각 영역 점수를 골고루 분포 (0~10점 범위)
- 초기 < 중간 < 최종 점수로 점진적 성장
- 총점: 초기(18~24점), 중간(24~36점), 최종(36~54점)

### 2. 시험 점수 생성 로직 개선
- `_generate_section_scores_for_total` 함수 개선
- 점진적 성장을 보장하는 로직 추가
- 하경은행 점수를 다른 영역과 동일하게 처리

### 3. 문제 정오답 정보
- Seed 데이터에서 ExamResult 생성 (선택적)
- QuizGenerationLog의 정오답 정보 확인 및 보완

## 수정 우선순위

1. ✅ 문제점 확인 및 분석
2. 🔄 시험 점수 생성 로직 수정
3. 🔄 Seed 데이터 수정 스크립트 작성
4. ⏳ Seed 데이터 재생성
5. ⏳ 문제 정오답 정보 확인 및 보완
