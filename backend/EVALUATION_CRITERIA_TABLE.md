# 📊 역량별 평가 기준표

## 🎯 평가 체계 개요

각 역량은 **100점 만점**으로 평가되며, 세부 항목별 점수를 합산하여 최종 점수를 산출합니다.

---

## 1️⃣ 지식 (Knowledge, 0-100점)

**평가 목적**: 정보의 사실 관계(정확성)만 평가

### 📋 평가 항목 (대화 유형별 상이)

#### A 유형 (상품 중심)
| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| **상품 정확성** | 70점 | RAG 자동 검증 결과 기반 (정확한 정보 비율) |
| **절차 지식** | 15점 | 신청/해지/변경 절차의 정확성 |
| **일반 금융 지식** | 10점 | 금융 상식, 규정 이해도 |
| **카테고리별 전문성** | 5점 | 해당 카테고리(수신/여신/카드) 특화 지식 |

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| **상품 지식** | 40점 | RAG 자동 검증 결과 기반 |
| **절차 지식** | 30점 | 신청/해지/변경 절차의 정확성 |

| **카테고리별 전문성** | 10점 | 해당 카테고리 특화 지식 |

#### C 유형 (절차 중심)
| 항목 | 만점 | 평가 기준 |

| **일반 은행 업무** | 20점 | 기본 은행 업무 지식 |

## 2️⃣ 기술 (Skill, 0-100점)

**평가 목적**: 응대 절차의 체계성 및 상담 주도성

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| **대화 흐름** | 20점 | • 인사 및 라포 형성 (5점)<br>• 니즈 파악 (5점)<br>• 해결책 제시 (5점)<br>• 마무리 및 향후 안내 (5점) |
| **목표 달성도** | 60점 | (달성한 목표 수 / 전체 목표 수) × 60점<br>※ 목표가 0개면 60점 |
| **상담 주도성** | 10점 | • 적극적 제안 (고객이 묻지 않은 정보 제공): 10점<br>• 기본 응대 (질문에만 답변): 5점<br>• 소극적/회피 (단답형): 0점 |
| **질문 사용** | 5점 | • 개방형 질문 활용, 고객 상황 파악: 5점<br>• 질문 없이 일방적 설명: 0점 |
| **피드백 루프** | 5점 | • 이해도 확인 또는 요약 1회 이상: 5점<br>• 확인 없이 진행: 0점 |

### ⚠️ 핵심 원칙
- ✅ **평가 대상**: 상담 프로세스, 목표 달성, 주도성
- ❌ **평가 제외**: 정보 정확성, 표현 방식, 태도

## 3️⃣ 명확성 (Clarity, 0-100점)

**평가 목적**: 표현 방식의 명확성 (정보 정확성이 아님)

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| **문장 구조** | 30점 | • 50자 이하 간결한 문장 위주: 30점<br>• 만연체나 중언부언: 15점 |
| **논리성** | 25점 | • 기승전결 명확, 인과관계 정확: 25점<br>• 앞뒤 말 안 맞거나 비약: 12점 |
| **용어의 적절성** | 30점 | • **최우수** (30점): 금융 용어 + 쉬운 풀이<br>• **우수** (20점): 표준 금융 용어 정확히 사용<br>• **미흡** (15점): 설명 없이 전문 용어만 나열<br>• **미흡** (10점): "그거", "돈 더 내는 거" 등 모호한 표현 |
| **숫자 표현** | 15점 | • 단위(%, 원, 개월) 정확히 명시: 15점<br>• 단위 누락이나 모호한 표현: 7점 |

### ⚠️ 핵심 원칙
- ✅ **평가 대상**: 표현 방식 (용어 선택, 문장 구조, 숫자 단위)
- ❌ **평가 제외**: 정보의 사실 관계 (지식 평가 영역)
- 📌 **예시**: "연회비는 무료부터 시작" → 표현 자체는 명확함 (사실 여부는 지식 평가)

## 4️⃣ 친절도 (Kindness, 0-100점)

**평가 목적**: 태도와 정중함, 고객 존중

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| **기본 정중함** | 30점 | • 쿠션어 및 존칭 적절히 사용: 30점<br>• 명령조/반말 사용: 15점 |
| **공감과 경청** | 30점 | • 고객 상황/감정 반응 멘트 1회 이상: 30점<br>• 기계적 응답만: 0점<br>※ All or Nothing |
| **선택권 존중** | 20점 | • 청유형 ("~하는 건 어떨까요?"): 20점<br>• 강요형 ("무조건 해야 합니다"): 0점 |
| **부정 표현 회피** | 20점 | • 태도적 부정 표현 없음: 20점<br>• "안 돼요", "몰라요" 등 발견: 0점<br>※ "수수료 없음" 등 사실적 부정 표현은 감점 안 함 |

### ⚠️ 핵심 원칙
- ✅ **평가 대상**: 태도와 정중함 (존칭, 공감, 선택권 존중)
- ❌ **평가 제외**: 정보 정확성 (지식), 표현 명확성 (명확성)
- 📌 **예시**: "연회비는 무료부터 시작" → 정중함은 OK (사실 여부는 지식, 명확성은 명확성 평가)

## 5️⃣ 자신감 (Confidence, 0-100점)

**평가 목적**: 어조의 확신성 (정보 정확성이 아님)

| 항목 | 만점 | 평가 기준 |
|------|------|-----------|
| **확정적 표현** | 80점 | • "가능합니다", "됩니다" 등 명확한 종결어미 80% 이상: 80점<br>• "~같아요", "아마도" 등 불확실한 표현 남발: 40점 |
| **불확실성 회피** | 20점 | • 모호한 표현 없음: 20점<br>• 모호한 표현 1-2회: 10점<br>• 모호한 표현 3회 이상: 0점 |

### ⚠️ 핵심 원칙
- ✅ **평가 대상**: 어조의 확신성 ("~입니다" vs "~같아요")
- ❌ **평가 제외**: 정보 정확성 (지식), 표현 명확성 (명확성)
- 📌 **예시**: "연회비는 무료부터 시작합니다" (확신 있음, OK) vs "무료인 것 같아요" (불확실, 감점)

## 💡 전달력 (Clarity + Confidence, 0-100점)

**산출 방식**: (명확성 점수 + 자신감 점수) ÷ 2

전달력은 명확성과 자신감을 종합한 역량으로, 별도의 세부 항목 없이 두 역량의 평균으로 계산됩니다.

## 🎯 평가 시 주의사항

### 1. 역량 간 중복 평가 금지
- **지식**: 정보의 사실 관계만
- **명확성**: 표현 방식만
- **친절도**: 태도와 정중함만
- **자신감**: 어조의 확신성만
- **페르소나**: 고객 타입별 전략만

### 2. 실제 대화 로그 기반 평가
- 대화에 없는 표현은 절대 언급 금지
- Before → After 형식 제안 시 Before는 반드시 실제 대화 로그의 표현

### 3. RAG 자동 검증 결과 최우선
- 지식 평가 시 RAG 자동 검증 결과를 100% 신뢰
- LLM의 자의적 판단보다 객관적 데이터 우선

### 4. 일관성 유지
- 동일한 시나리오는 동일한 점수 산출 (temperature=0.0)
- 평가 기준의 일관된 적용
