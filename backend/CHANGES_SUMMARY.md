# 멘토 배정 및 초기화 로직 개선 요약

## 목표
1. 각 기수(1, 2, 3, 4기)마다 독립적인 15명의 멘토 배정
2. 초기화 시 1-3기 데이터는 유지, 4기만 재생성
3. AWS 업로드 시에도 1-3기 데이터 유지

## 변경 사항

### 1. 초기화 로직 수정 (`initialize_demo_data`)
- **기존**: 모든 데이터 삭제 후 재생성
- **변경**: 
  - 1-3기 데이터는 기존 데이터 확인 후 있으면 스킵
  - 4기 데이터만 삭제 및 재생성
  - 각 기수별 독립적인 멘토 할당

### 2. 4기 데이터만 삭제하는 메서드 추가 (`_delete_cohort_4_data`)
- 4기 관련 데이터만 선택적으로 삭제
- 1-3기 데이터는 보존

### 3. 매칭 로직 개선 (진행 중)
- 각 기수별로 독립적인 15명의 멘토만 할당
- 멘토가 여러 기수를 담당하지 않도록 수정
