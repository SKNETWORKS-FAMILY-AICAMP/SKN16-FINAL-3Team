# 멘토 기수별 배정 수정 요약

## 문제 상황
- 실제 각 기수에 멘티를 맡은 멘토 수:
  - 1기: 15명
  - 2기: 15명
  - 3기: 15명
  - 4기: 29명

- 대시보드 표시 수:
  - 1기: 4명
  - 2기: 5명
  - 3기: 9명
  - 4기: 35명

- 문제 원인:
  - 멘토가 여러 기수의 멘티를 맡고 있음 (25명)
  - `_serialize_record`가 멘토가 여러 기수를 담당할 때 가장 최근 기수만 표시
  - 따라서 4기를 맡은 멘토가 많으면, 다른 기수에서도 4기로만 표시됨

## 수정 작업
1. 각 기수별로 멘토를 독립적으로 재배정
   - 각 기수당 멘토 15명 (멘토 1명당 멘티 2명)
   - 멘티 30명씩 각 기수에 배정

2. 결과:
   - 1기: 15명 (멘티 30명, 멘토당 2명)
   - 2기: 15명 (멘티 30명, 멘토당 2명)
   - 3기: 15명 (멘티 30명, 멘토당 2명)
   - 4기: 15명 (멘티 30명, 멘토당 2명)

3. 남은 이슈:
   - 여전히 여러 기수를 담당하는 멘토가 15명 있음
   - 이는 4기 배정 시 배정 가능한 멘토가 부족했기 때문
   - 대시보드에서 1기가 0명으로 표시됨 (1기 멘토가 4기도 맡아서 4기로만 표시)

## 다음 단계
각 멘토가 정확히 한 기수만 담당하도록 완전히 분리해야 대시보드에서 올바르게 표시됩니다.
