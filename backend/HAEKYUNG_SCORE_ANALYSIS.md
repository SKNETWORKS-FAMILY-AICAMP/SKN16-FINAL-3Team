# 하경은행 영역 시험 점수 분석

## 문제 발견

### 확인 결과
- **총 300개의 ExamScore 중**:
  - 10/10인 경우: **261명 (87%)**
  - 10/10이 아닌 경우: 39명
    - 2/10: 12명
    - 3/10: 17명
    - 4/10: 1명
    - 7/10: 1명
    - 8/10: 3명
    - 9/10: 5명

### 원인 분석

#### 1. Seed 데이터 (cohort_3_2025.json 등)
- Seed JSON 파일에서 많은 경우에 `"하경은행": 10`으로 하드코딩되어 있음
- 예시:
  ```json
  "score_data": "{\"은행업무\": 6, \"상품개발 및 운용\": 1, \"신용분석 및 리스크관리\": 0, \"외환\": 0, \"은행지식 및 관련법률\": 1, \"하경은행\": 10}"
  ```

#### 2. 실제 저장된 데이터
- ExamScore.score_data에 `"하경은행": 10`으로 저장되어 있음
- 이는 seed 데이터를 로드할 때 그대로 반영된 것

#### 3. 학습 이력 표시 로직
- 학습 이력 API는 정규화 로직을 통해 10점을 10/10으로 표시함
- 문제는 seed 데이터 자체에 있음

## 문제 판단

### 시나리오 1: 의도된 설정
- 하경은행 영역이 비교적 쉬워서 대부분 만점을 받는 것이 의도된 것일 수 있음
- 하지만 87%가 만점인 것은 비현실적임

### 시나리오 2: Seed 데이터 생성 오류
- Seed 데이터 생성 시 하경은행 점수를 항상 10으로 설정하는 로직이 있거나
- Seed JSON 파일 생성 시 실수가 있었을 가능성

## 해결 방안

1. **Seed 데이터 확인**: cohort_1, 2, 3, 4 JSON 파일의 하경은행 점수 분포 확인
2. **시험 점수 생성 로직 확인**: `_generate_section_scores_for_total` 함수가 하경은행 점수를 특별히 처리하는지 확인
3. **Seed 데이터 수정**: 하경은행 점수를 다양하게 분포시키도록 수정

- 필요시 Seed 데이터 수정 또는 생성 로직 수정
