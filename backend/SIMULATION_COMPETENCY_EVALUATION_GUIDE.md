# 🎯 시뮬레이션 역량 평가 가이드

## 📌 개요

시뮬레이션 평가는 **4가지 핵심 역량**을 종합적으로 평가합니다:

1. **지식 (Knowledge)** - 정보의 정확성
2. **기술 (Skill)** - 응대 절차와 목표 달성
3. **친절도 (Kindness)** - 고객 중심의 배려 있는 언어
4. **전달력 (Delivery)** - 명확성과 자신감

각 역량은 **0~100점**으로 평가되며, GPT-4o가 대화 내용을 분석하여 점수와 피드백을 생성합니다.

### 종합 점수 계산 방식

종합 점수는 각 역량의 **가중 평균**으로 계산됩니다:

| 역량 | 가중치 |
|------|--------|
| **지식 (Knowledge)** | 30% |
| **기술 (Skill)** | 30% |
| **친절도 (Kindness)** | 20% |
| **전달력 (Delivery)** | 20% |

**계산 예시:**
```
지식: 90점 × 0.30 = 27.0점
기술: 85점 × 0.30 = 25.5점
친절도: 80점 × 0.20 = 16.0점
전달력: 88점 × 0.20 = 17.6점

종합 점수 = 27.0 + 25.5 + 16.0 + 17.6 = 86.1점
```

## 🔄 전체 평가 프로세스

```
시뮬레이션 대화 종료
    ↓
[1단계] 자동 검증 (지식 역량)
    → 제품 지식 자동 검증 (RAG 기반)
    → 정확도 계산
    ↓
[2단계] GPT-4o 종합 평가
    → 4가지 역량 모두 평가
    → 점수 + 피드백 생성
    ↓
[3단계] 최종 리포트 생성
    → 역량별 점수 및 피드백
    → 종합 요약 및 개선 방안
```

## 1️⃣ 지식 (Knowledge) - 정보의 정확성

### 🎯 목적
직원이 제공한 **제품 정보나 업무 절차 설명이 정확한지** 평가합니다.

### 📊 평가 방식

#### 자동 검증 (상품 데이터 있는 경우)
- **3단계 검증**: Keyword → Semantic → LLM
- **정확도 계산**: 정확한 정보 개수 / 전체 정보 개수
- **점수 변환**: 정확도 80% → 지식 점수 80점

#### LLM 평가 (상품 데이터 없는 경우)
- 업무 절차 설명의 정확성
- 일반적인 금융 지식 및 규정 이해도
- 절차 설명의 논리성

### ✅ 평가 기준

**잘한 점:**
- ✓ 정확한 금리, 한도, 조건 등 구체적 수치 제시
- ✓ 실제 제품 데이터와 일치하는 정보 제공
- ✓ 업무 절차를 정확하게 설명

**개선점:**
- ✗ 잘못된 정보 제공 (예: "금리 3.5%" → 실제로는 "2.15%")
- ✗ 모호한 정보 제공 (예: "최소 100" → "최소 100만원"으로 명확히)
- ✗ 일반적인 금융 지식 오류

### 📝 점수 계산 예시

```
정확한 정보: 8개
부정확한 정보: 2개
전체 정보: 10개

정확도 = 8 / 10 = 80%
지식 점수 = 80점
```

## 2️⃣ 기술 (Skill) - 응대 절차와 목표 달성

### 🎯 목적
직원이 **체계적인 응대 절차를 따르고 목표를 달성했는지** 평가합니다.

### 📊 평가 방식

#### 1. 대화 흐름 평가 (40%)
- **인사**: 첫 발화에 인사 포함 여부
- **요구 파악**: 고객 니즈 파악을 위한 질문 사용
- **정보 제공**: 체계적인 정보 제공
- **마무리**: 정중한 마무리 인사

#### 2. 목표 달성도 (40%)
- 시뮬레이션에서 설정된 목표 달성 여부
- 예: "송금 목적 확인", "수수료 안내", "추가 서비스 제안" 등
- 달성률 = 달성한 목표 수 / 전체 목표 수

#### 3. 피드백 루프 (20%)
- 요약 및 추가 확인 여부
- 고객의 추가 질문에 대비한 정보 제공

### ✅ 평가 기준

**잘한 점:**
- ✓ 인사 → 요구파악 → 정보제공 → 마무리 순서 준수
- ✓ 목표를 모두 달성
- ✓ 대화 마무리 시 요약 및 추가 확인

**개선점:**
- ✗ 인사 없이 바로 본론으로 들어감
- ✗ 고객 니즈 파악 없이 일방적으로 정보 제공
- ✗ 목표를 일부 놓침 (예: "송금 목적 확인" 미달성)
- ✗ 마무리 없이 대화 종료

### 📝 점수 계산 예시

```
대화 흐름 점수: 85점
목표 달성도: 3/4 = 75점
피드백 루프: 90점

기술 점수 = 85 × 0.4 + 75 × 0.4 + 90 × 0.2 = 82점
```

## 3️⃣ 친절도 (Kindness) - 고객 중심의 배려

### 🎯 목적
직원이 **고객을 배려하는 언어를 사용했는지** 평가합니다.

### 📊 평가 방식

GPT-4o가 대화 내용을 분석하여 다음을 평가:

#### 1. 긍정 표현 사용
- "감사합니다", "도와드리겠습니다", "안내해 드리겠습니다"
- 정중한 어투: "~해주세요", "~드리겠습니다"

#### 2. 고객 선택권 존중
- 강제 느낌 없는 표현
- 예: "더 빠르고 정확합니다" → "더 편리할 수 있습니다"

#### 3. 부정 표현 회피
- "안 됩니다", "불가능합니다", "모르겠어요" 같은 부정 표현 감점
- 명령형/무뚝뚝한 표현 감점

### ✅ 평가 기준

**잘한 점:**
- ✓ 정중하고 배려 있는 어투 사용
- ✓ 고객 선택권을 존중하는 표현
- ✓ 긍정적인 표현 자주 사용

**개선점:**
- ✗ 부정 표현 사용 (예: "안 됩니다")
- ✗ 명령형 표현 (예: "하세요" → "해주세요")
- ✗ 고객 선택을 제한하는 표현 (예: "더 빠르고 정확합니다")

### 📝 점수 계산 예시

```
긍정 표현: 5회 사용 → +50점
부정 표현: 1회 사용 → -20점
고객 선택권 존중: 양호 → +30점

친절도 점수 = 60점
```

## 4️⃣ 전달력 (Delivery) - 명확성과 자신감

### 🎯 목적
직원이 **명확하고 확신 있게 정보를 전달했는지** 평가합니다.

전달력은 **명확성(Clarity)**과 **자신감(Confidence)**의 평균으로 계산됩니다.

### 📊 평가 방식

#### 명확성 (Clarity) 평가

**1. 문장 구조 (40%)**
- 간결하고 명료한 문장 (100자 이내 권장)
- 한 문장에 한 가지 내용만 전달

**2. 논리성 (30%)**
- 논리적 연결어 사용
- 구체적 정보 제공

**3. 용어 평이성 (30%)**
- 전문용어보다 쉬운 말 사용
- 예: "거치기간" → "이자만 내는 기간"
- 예: "초저금리" → "아주 낮은 금리"
- 예: "LTV" → "담보인정비율"

**4. 숫자 표현의 명확성**
- "최소 100" → "최소 100만원" (단위 명시)

#### 자신감 (Confidence) 평가

**1. 확정적 표현 사용**
- "합니다", "됩니다", "가능합니다", "맞습니다"
- "~입니다", "~됩니다"

**2. 불확실한 표현 회피**
- "~같아요", "~일 수도 있어요", "~보이는데요" 감점
- "확실하진 않지만", "아마도", "모르겠지만" 감점

**3. 부정확한 정보를 확신 있게 말한 경우**
- 지식 평가에서 언급한 부정확한 정보를 확신 있게 말한 경우도 감점

### ✅ 평가 기준

**명확성 - 잘한 점:**
- ✓ 문장이 간결하고 명확함
- ✓ 복잡한 금융용어를 쉽게 풀어서 설명
- ✓ 숫자 표현에 단위 명시

**명확성 - 개선점:**
- ✗ 너무 긴 문장이나 복잡한 표현
- ✗ 모호한 숫자 표현 (예: "최소 100")
- ✗ 전문용어 남용

**자신감 - 잘한 점:**
- ✓ 확정적 표현 자주 사용
- ✓ 불확실한 표현 회피

**자신감 - 개선점:**
- ✗ "~같아요", "~보이는데요" 같은 불확실한 표현
- ✗ 부정확한 정보를 확신 있게 말함

### 📝 점수 계산 예시

```
명확성 점수: 85점
자신감 점수: 80점

전달력 점수 = (85 + 80) / 2 = 82.5점 → 83점
```

## 📋 피드백 생성 원칙

### 1. 구체적인 예시 포함
- 대화에서 실제로 사용한 표현을 인용 (따옴표 사용)
- 예: "'최소 100' → '최소 100만원'으로 명확히 표현하세요"

### 2. 잘한 점 먼저 언급
- 긍정적인 부분을 먼저 칭찬
- 개선점은 그 다음에 제시

### 3. Before → After 형식
- 개선이 필요한 표현은 구체적인 개선 방안 제시
- 예: "'더 빠르고 정확합니다' → '더 편리할 수 있습니다'"

### 4. 중복 제거
- 같은 오류를 여러 역량에서 반복하지 않기
- 지식 평가에서 상세히 다룬 오류는 다른 역량에서 간단히 참조만

### 5. 실용적 조언
- 다음 시뮬레이션에서 바로 적용 가능한 팁 제공

## 🔍 평가 예시

### 시나리오: 정기예금 상담

**대화 내용:**
- 직원: "안녕하세요. 정기예금 상담 도와드리겠습니다."
- 고객: "금리가 궁금해요."
- 직원: "정기예금 12개월 기본금리는 연 2.15%입니다. 최소 100만원부터 가입 가능합니다."
- 고객: "그럼 가입하겠습니다."
- 직원: "감사합니다. 추가로 궁금한 점 있으시면 언제든지 문의해 주세요."

### 평가 결과

| 역량 | 점수 | 평가 |
|------|------|------|
| **지식** | 95점 | 금리 정보 정확 (2.15%), 최소 가입금액 명확히 제시 |
| **기술** | 90점 | 인사 → 요구파악 → 정보제공 → 마무리 순서 준수, 목표 달성 |
| **친절도** | 85점 | 정중한 어투, 고객 선택권 존중 |
| **전달력** | 88점 | 명확한 표현, 확신 있는 어투 |

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 지식 점수와 전달력 점수의 차이는?
- **지식**: 정보가 **정확한지** 평가 (내용의 정확성)
- **전달력**: 정보를 **명확하고 확신 있게** 전달했는지 평가 (전달 방식)

예를 들어, "금리 3.5%입니다"라고 확신 있게 말했다면:
- 지식 점수: 감점 (잘못된 정보)
- 전달력 점수: 감점 (부정확한 정보를 확신 있게 말함)

### Q2. 친절도와 전달력의 차이는?
- **친절도**: 고객을 **배려하는 언어** 사용 여부 (어투, 표현)
- **전달력**: 정보를 **명확하고 확신 있게** 전달했는지 (명확성, 자신감)

### Q3. 목표 달성도가 낮으면 기술 점수가 낮나요?
네, 목표 달성도는 기술 점수의 40%를 차지합니다. 하지만 대화 흐름과 피드백 루프도 함께 평가되므로, 목표를 일부 놓쳤더라도 다른 부분이 우수하면 점수가 보완될 수 있습니다.

### Q4. 불확실한 표현은 어느 역량에서 평가되나요?
**전달력(자신감)**에서 평가됩니다. 지식 점수에는 반영되지 않습니다.

예: "금리가 2.15%인 것 같아요"
- 지식 점수: 정확한 정보이므로 감점 없음
- 전달력 점수: "~같아요" 표현으로 자신감 감점

### Q5. 모든 역량이 동일한 가중치인가요?
아니요. 종합 점수 계산 시 다음과 같은 가중치가 적용됩니다:
- **지식**: 30% (정보의 정확성이 가장 중요)
- **기술**: 30% (응대 절차와 목표 달성이 중요)
- **친절도**: 20%
- **전달력**: 20%

지식과 기술이 각각 30%로 가장 높은 가중치를 가지며, 친절도와 전달력은 각각 20%입니다.
