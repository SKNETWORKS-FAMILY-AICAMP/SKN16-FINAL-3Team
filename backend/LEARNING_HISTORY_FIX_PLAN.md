# 학습 이력 대시보드 문제 분석 및 해결 계획

## 🔍 문제 분석

### 1. 퀴즈 데이터 (랜덤/맞춤)
**현상**: 모든 영역별 점수가 `0/0`으로 표시됨
- 총점은 표시됨 (40~100점)
- 영역별 점수는 모두 `0/0`

**원인**:
- 퀴즈 문제의 카테고리 이름이 `CATEGORY_KEYS`와 일치하지 않음
- 예: 문제에 "은행업무"라는 카테고리 이름이 저장되어 있는데, `CATEGORY_KEYS`에는 "금융영업"만 있음

### 2. 시험 데이터 (중간/최종 평가)
**현상**: 영역별 점수가 `0/0`으로 표시됨
- 초기 평가는 정상 표시됨 (예: 3/10, 4/10)
- 중간/최종 평가는 모두 `0/0`

**원인**:
- 중간/최종 평가의 `score_data`가 없거나 빈 값
- `TrainingCenterRecord.section_scores`도 없거나 모두 0

## 🔧 해결 방안

### 1. 퀴즈 카테고리 매핑 추가 ✅
- 카테고리 이름을 `CATEGORY_KEYS`로 매핑하는 로직 추가
- 예: "은행업무" → "금융영업"

### 2. 시험 데이터 처리 개선 ⏳
- `score_data`가 없는 경우 처리 로직 추가
- `ExamResult`를 통한 문제별 점수 집계로 대체
