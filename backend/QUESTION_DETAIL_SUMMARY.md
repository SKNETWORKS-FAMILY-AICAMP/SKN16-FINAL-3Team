# 문제별 정오답 확인 가능 여부 요약

## 현재 가능한 것

### ✅ 시험 (ExamScore)
- **문제별 정오답 확인 가능**
- API: `/api/exam/results/{exam_score_id}`
- 각 문제의 q_id, 사용자 답변, 정오답 여부 확인 가능

### ⚠️ 퀴즈 (QuizGenerationLog)
- **데이터는 저장되지만 API에서 제공 안 됨**
- `questions`와 `answers` 필드에 정보가 있음
- 하지만 학습 이력 API는 카테고리별 통계만 제공

## 현재 불가능한 것

### ❌ 학습 이력에서 문제별 상세 정보
- 현재 학습 이력 API는 "금융영업 8/10" 같은 통계만 제공
- "1번 문제 맞음, 2번 문제 틀림" 같은 문제별 정보는 없음

## 해결 방안

학습 이력 API에 문제별 상세 정보를 추가하면:
- 각 문제의 q_id
- 문제 내용
- 사용자 답변
- 정답
- 정오답 여부
- 카테고리

이 모든 정보를 확인할 수 있습니다.
