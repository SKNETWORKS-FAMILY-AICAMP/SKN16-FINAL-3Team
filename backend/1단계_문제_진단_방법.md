# 1단계: 문제 진단 방법 안내

## 방법 1: Swagger UI 사용 (가장 쉬움) ⭐ 추천

### 1-1. 서버가 실행 중인지 확인
```bash
# Docker를 사용하는 경우
docker-compose ps

# 또는 브라우저에서 확인
http://localhost:8000/docs 접속
```

### 1-2. Swagger UI 접속
브라우저에서 다음 주소로 접속:
```
http://localhost:8000/docs
```

### 1-3. 관리자 로그인 토큰 획득

1. **로그인 API 호출**
   - Swagger UI에서 `/auth/login` 찾기
   - "Try it out" 클릭
   - Request body에 다음 입력:
   ```json
   {
     "username": "admin@bank.com",
     "password": "admin123"
   }
   ```
   - "Execute" 클릭
   - Response에서 `access_token` 복사 (예: `eyJhbGc...`)

2. **Authorization 설정**
   - Swagger UI 오른쪽 상단의 "Authorize" 버튼 클릭
   - Value 필드에 `Bearer {토큰}` 형식으로 입력
     - 예: `Bearer eyJhbGc...`
   - "Authorize" 클릭

### 1-4. 진단 API 호출

#### 멘토 매칭 진단
1. `/dashboard/admin/diagnose-matching/{mentor_name}` 찾기
2. "Try it out" 클릭
3. `mentor_name`에 `권도형` 입력
4. "Execute" 클릭
5. Response 확인

#### 멘티 매칭 진단
1. `/dashboard/admin/diagnose-mentee-matching/{mentee_name}` 찾기
2. "Try it out" 클릭
3. `mentee_name`에 `홍예미` 또는 `황나미` 입력
4. "Execute" 클릭
5. Response 확인

## 방법 2: 프론트엔드에서 직접 확인

### 2-1. 관리자 계정으로 로그인
```
URL: http://localhost:3000
이메일: admin@bank.com
비밀번호: admin123
```

### 2-2. 브라우저 개발자 도구 사용
1. F12 또는 우클릭 → "검사" 클릭
2. "Console" 탭 열기
3. 다음 JavaScript 코드 실행:

```javascript
// 1. 로그인 (이미 로그인되어 있다면 생략)
fetch('http://localhost:8000/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams({
    username: 'admin@bank.com',
    password: 'admin123'
  })
})
.then(res => res.json())
.then(data => {
  const token = data.access_token;
  console.log('토큰:', token);
  
  // 2. 권도형 멘토 매칭 진단
  return fetch('http://localhost:8000/dashboard/admin/diagnose-matching/권도형', {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
})
.then(res => res.json())
.then(data => {
  console.log('권도형 멘토 매칭 상태:', JSON.stringify(data, null, 2));
  
  // 3. 홍예미 멘티 매칭 진단
  return fetch('http://localhost:8000/dashboard/admin/diagnose-mentee-matching/홍예미', {
    headers: {
      'Authorization': `Bearer ${localStorage.getItem('token') || 'YOUR_TOKEN'}`
    }
  });
})
.then(res => res.json())
.then(data => {
  console.log('홍예미 멘티 매칭 상태:', JSON.stringify(data, null, 2));
});
```

## 방법 3: curl 명령어 사용 (터미널/CMD)

### 3-1. 로그인하여 토큰 획득
```bash
# Windows (PowerShell)
$response = Invoke-RestMethod -Uri "http://localhost:8000/auth/login" -Method POST -ContentType "application/x-www-form-urlencoded" -Body @{
    username = "admin@bank.com"
    password = "admin123"
}
$token = $response.access_token
Write-Host "토큰: $token"

# Linux/Mac (Bash)
TOKEN=$(curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin@bank.com&password=admin123" | jq -r '.access_token')
echo "토큰: $TOKEN"
```

### 3-2. 멘토 매칭 진단
```bash
# Windows (PowerShell)
Invoke-RestMethod -Uri "http://localhost:8000/dashboard/admin/diagnose-matching/권도형" `
  -Method GET `
  -Headers @{ "Authorization" = "Bearer $token" } | ConvertTo-Json -Depth 10

# Linux/Mac (Bash)
curl -X GET "http://localhost:8000/dashboard/admin/diagnose-matching/권도형" \
  -H "Authorization: Bearer $TOKEN" | jq '.'
```

### 3-3. 멘티 매칭 진단
```bash
# Windows (PowerShell)
Invoke-RestMethod -Uri "http://localhost:8000/dashboard/admin/diagnose-mentee-matching/홍예미" `
  -Method GET `
  -Headers @{ "Authorization" = "Bearer $token" } | ConvertTo-Json -Depth 10

# Linux/Mac (Bash)
curl -X GET "http://localhost:8000/dashboard/admin/diagnose-mentee-matching/홍예미" \
  -H "Authorization: Bearer $TOKEN" | jq '.'
```

## 응답 결과 해석

### 정상적인 경우 (매칭이 되어 있음)
```json
{
  "mentor": {
    "id": 1001,
    "name": "권도형",
    "email": "...",
    "role": "mentor"
  },
  "all_relations": [
    {
      "relation_id": 1,
      "mentor_id": 1001,
      "mentee_id": 1016,
      "mentee_name": "홍예미",
      "is_active": true,  ✅ 활성 상태
      "matched_at": "2025-03-04T14:00:00"
    }
  ],
  "active_relations": [...],  ✅ 활성 관계 있음
  "active_count": 2,
  "total_count": 2
}
```

### 문제가 있는 경우 1: 매칭이 비활성화됨
```json
{
  "active_relations": [],  ❌ 활성 관계 없음
  "active_count": 0,
  "all_relations": [
    {
      "is_active": false  ❌ 비활성 상태
    }
  ]
}
```

### 문제가 있는 경우 2: 매칭 관계가 없음
```json
{
  "all_relations": [],  ❌ 관계 자체가 없음
  "active_relations": [],
  "active_count": 0,
  "total_count": 0
}
```

## 다음 단계

진단 결과에 따라:

1. **`is_active: false`인 경우**
   - 관리자 대시보드에서 재매칭 필요
   - 또는 DB에서 직접 활성화

2. **매칭 관계가 없는 경우**
   - 관리자 대시보드에서 새로 매칭 필요

3. **사용자를 찾을 수 없는 경우**
   - 이름 확인 (띄어쓰기, 한글/영문 확인)
   - DB에서 실제 이름 확인 필요

## 빠른 확인 스크립트 (Python)

프로젝트 루트에 `diagnose_matching.py` 파일 생성:

```python
import requests
import json

BASE_URL = "http://localhost:8000"

# 1. 로그인
login_response = requests.post(
    f"{BASE_URL}/auth/login",
    data={"username": "admin@bank.com", "password": "admin123"}
)
token = login_response.json()["access_token"]
print(f"✅ 로그인 성공")

# 2. 권도형 멘토 진단
mentor_response = requests.get(
    f"{BASE_URL}/dashboard/admin/diagnose-matching/권도형",
    headers={"Authorization": f"Bearer {token}"}
)
print("\n=== 권도형 멘토 매칭 상태 ===")
print(json.dumps(mentor_response.json(), indent=2, ensure_ascii=False))

# 3. 홍예미 멘티 진단
mentee1_response = requests.get(
    f"{BASE_URL}/dashboard/admin/diagnose-mentee-matching/홍예미",
    headers={"Authorization": f"Bearer {token}"}
)
print("\n=== 홍예미 멘티 매칭 상태 ===")
print(json.dumps(mentee1_response.json(), indent=2, ensure_ascii=False))

# 4. 황나미 멘티 진단
mentee2_response = requests.get(
    f"{BASE_URL}/dashboard/admin/diagnose-mentee-matching/황나미",
    headers={"Authorization": f"Bearer {token}"}
)
print("\n=== 황나미 멘티 매칭 상태 ===")
print(json.dumps(mentee2_response.json(), indent=2, ensure_ascii=False))
```

실행:
```bash
python diagnose_matching.py
```
